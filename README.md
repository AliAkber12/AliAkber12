## About Me

I'm **Ali Akber**, a software engineering student at **Iqra University, Karachi**, focused on building useful products with **Python, large language models, retrieval-augmented generation (RAG), agentic workflows, and backend APIs**.

I work across the AI application stack: connecting models to real data, building API layers, designing workflows, and creating interfaces that people can use. My interests span both **AI engineering** and **full-stack product development**.

- **AI application development:** LLM integrations, prompt workflows, RAG and semantic search.
- **Backend engineering:** Python, FastAPI, REST APIs, relational databases and service design.
- **Agentic systems:** Tool calling, multi-step workflows and evaluation of model behavior.
- **Product building:** SaaS concepts, automation tools, dashboards and Java desktop applications.
- **Opportunities:** Open to relevant internships, engineering collaborations and project-based work.

> My focus is on measurable functionality, clear architecture and honest documentation — not just impressive-looking demos.

### How I Approach Projects

1. **Define the workflow:** What should the user accomplish, and what can fail?
2. **Design the data and APIs:** Use sensible schemas, reusable services and validations.
3. **Implement the core behavior:** Prioritize reliable end-to-end functionality over decorative features.
4. **Test edge cases:** Invalid inputs, duplicate actions, state changes, API failures and missing data.
5. **Iterate:** Improve usability, code quality and documentation based on real results.
